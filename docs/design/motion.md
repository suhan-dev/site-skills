# Motion

> Generated by `node tools/design-inventory.mjs` from every `.css` file under `skills/*/assets/`, the style sheet inside `google-signin-team-gate/assets/functions/_middleware.js`, and the timers in the skill JS. Do not edit by hand: change the code and run the command again.
> The roles in the first table and the explanations of the JS timers are written by hand in the script; the script finds every value and line in the code and stops when one is gone.

Durations are shown in ms. **Easing** "not written" means the CSS initial value `ease` applies. **Reduced motion** says whether a `prefers-reduced-motion: reduce` rule turns the motion off (with a link to that rule) or whether it is kept.
