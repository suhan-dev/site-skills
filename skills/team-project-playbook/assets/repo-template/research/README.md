# research — topics

Topic folders. Unlike the chronological logs (`logs/`), these hold the **current conclusions** and are rewritten as
they change.

Each topic folder has:

- `README.md`: the current team consensus, the assumptions table (parameter · value · reason · source), open questions;
- `notes/MMDD_name_topic.md`: working notes, linked from the logs.
