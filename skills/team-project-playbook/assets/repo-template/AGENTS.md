# AGENTS.md

This file is for AI coding assistants other than Claude (Codex, Cursor, Gemini, Copilot and the like).
The rules for every assistant in this repository are in **[CLAUDE.md](CLAUDE.md)**. Read it first and follow it; if
this file and CLAUDE.md ever differ, CLAUDE.md wins.

The short version:

- Talk with the user in {{TEAM_LANGUAGE}}. Write everything in the repository in English.
- Never commit passwords, keys, tokens, paper PDFs or personal information.
- Do not edit a closed week's log or someone else's log.
- Mark guesses as guesses. Numbers come from scripts in `code/`.
- The website files are edited only by the site owner's session.
- Never push to `main`; open a branch and a pull request.
