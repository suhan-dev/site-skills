# references

Material for {{PROJECT_TITLE}}. The site's References tab reads this file and [papers.csv](papers.csv).

- Link lists use the form `- [Name](url) — description`. End the description with `(unverified)` or `(verified)` and
  the site shows a mark.
- Papers go into `papers.csv`, one row each. Put your id in `read_by` when you have read it, and a one-line memo in
  `note`.
- Do not upload paper PDFs (copyright; `.gitignore` blocks them and the build check fails on them). Link the DOI.
  Keep your own copy outside the repository.
- Paper notes go in `notes/year-firstauthor-keyword.md` (for example `notes/2021-hart-fin-losses.md`).
