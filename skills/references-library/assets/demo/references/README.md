## Notation
We write the fin parameter as $m^2 = hP/(kA)$, as in the 2021 rod paper. The steady profile is then
$$T(x) = T_\infty + (T_0 - T_\infty)\,\frac{\cosh m(L - x)}{\cosh mL}.$$
