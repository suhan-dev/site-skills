1. What this page shows

This is placeholder text for the demo. Select any words in it and a small bar appears with Copy and Comment (on a phone just Comment). It opens the team chat with the passage quoted, and the passage gets a thin underline once it is sent.

Every comment keeps the words around it, so the mark finds its place again after the rest of the page is edited. If the passage itself is rewritten, the comment stays in the chat and simply has no mark.

2. Two ideas

Here is a passage that two people read differently. A comment on it is a better place for the question than a message with a screenshot, because the link in the chat brings everyone back to the same line.

The chat has two tabs. All is the whole conversation; This page holds only the comments on what is on screen, with a count next to it.
